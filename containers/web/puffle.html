Tu puffle, tu computadora

Conecta tu puffle para conversar y pedir música desde tu propio iglú. Tus cuentas permanecen en tu computadora; las visitas pueden ver los globos, pero no controlar tu música.

  1. Descarga el acompañante y extrae el archivo. Requiere Python 3.11 o posterior. Para Música y Safari necesitas una Mac.
  2. Desde la carpeta extraída, ejecuta python3 -m experiments.puffle_sim.connect_server. Abre la conexión local y conecta voluntariamente tu cuenta. Usar ChatGPT puede consumir cuota y créditos disponibles; administra tus límites antes de continuar.
  3. Ejecuta python3 -m production.puffle.companion pair --url URL. Entra a tu iglú y escribe el código que te muestre. Confirma que el pingüino indicado sea el tuyo en tu computadora.
  4. Para conversar y usar Música, ejecuta python3 -m production.puffle.companion run --music-mac. Para Apple Music en Safari usa run --music-safari-window-id ID, con tu ventana dedicada abierta. Para Spotify usa run --spotify, después de conectarlo en la página local.

Puedes detener el acompañante con Ctrl+C. Para retirar el vínculo escribe puffle desconectar en tu iglú o ejecuta python3 -m production.puffle.companion disconnect. Desconecta tus cuentas desde la página local si también quieres revocar su acceso.
